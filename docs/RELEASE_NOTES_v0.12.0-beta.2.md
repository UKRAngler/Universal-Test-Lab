# Universal Test Lab v0.12.0-beta.2

This beta adds an optional solo combined-battles sandbox.

## Changes

- Added 48 Domination maps with native ground, aircraft, and helicopter spawns.
- Added side and spawn selection plus A/B/C and team-spawn map markers.
- Fixed aircraft tactical-map zoom so the full aviation map is visible.
- Capture-point distance labels now appear only for ground vehicles.

No AI, score, active capture, or match progression is added in this mode.
